# 설계 근거

## 기존 설계 검토

| 출처 | 검토 결과 |
|---|---|
| 시판 굵은 손잡이 식기, 폼 튜브 | 지름이 정해져 있어 사용자별로 고를 수 없음. 폼은 위생·내구성 문제 |
| Makers Making Change 라이브러리 [R14, R15] | 저가형 키트 7종에는 식기 손잡이가 없음. 라이브러리 전체 검색은 사이트 접근 실패로 미확인 |
| 국립재활원 열린페이지, 경기도 3D보조기기 플랫폼 [R17, R19] | 설계 파일 직접 검색은 **팀이 해야 할 일**로 남김 (플랫폼 주소·계정 필요) |

결정: 지름을 바꿔 가며 여러 개를 출력해 보는 것이 핵심이므로 **매개변수 신규 설계**(`cad/built_up_handle.scad`)로 합니다.

## 설계 결정

| 결정 | 이유 |
|---|---|
| 원통형, 양 끝 3 mm 모따기 | R1·R3이 원통 손잡이로 측정. 모서리 압박 방지 |
| 지름 세 가지를 한 번에 출력 | R1의 선택 분포(29:6)와 R3의 쾌적 범위 모두 개인차를 보여 줌 |
| 손가락 홈 4개 (깊이 1.5 mm) | 미끄럼 방지. **연구 근거 없음 — 팀 판단.** 실사용에서 불편하면 `grooves = 0` |
| 관통 홈에 숟가락 손잡이를 끼움 | 숟가락을 바꿔도 다시 쓸 수 있음 |
