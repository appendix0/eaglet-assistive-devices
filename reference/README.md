# 참조 사례 (reference cases)

> **실제 사람이 아닙니다.** 아래 세 사례는 면담과 실사용이 필요한 단계를 **발표된 연구 결과로 대신해** 만든 예시입니다. 실제 사례(`cases/`)가 생기기 전에 절차, 템플릿, 설계 도구가 끝까지 이어지는지 확인하고, 다음 팀이 출발점으로 쓰도록 남깁니다.

| 사례 | 목표 동작 | 근거로 쓴 연구 | 기기 |
|---|---|---|---|
| [ref-01](ref-01-eating/) | 숟가락으로 식사 | 류마티스 관절염 환자 35명의 손가락 관절 각도 [R1], 건강한 성인 34명 [R2], 손잡이 지름 [R3] | 굵은 손잡이 (`cad/built_up_handle.scad`) |
| [ref-02](ref-02-door-knob/) | 원형 문고리 열기 | 조작력·회전 토크 접근성 기준 [R5, R6], 한국 고령자 악력 [R4], PETG 강도 [R7] | 문고리 레버 (`cad/knob_lever.scad`) |
| [ref-03](ref-03-writing/) | 펜으로 쓰기 | 기존 공개 설계 검토 [R15], 손잡이 지름 연구의 외삽 [R1–R3] | 기존 Pen Ball 우선, 대안으로 굵은 펜 손잡이 |

`[R번호]`는 [참고문헌](../docs/references.md)을 가리킵니다.

## 실제 사례와 무엇이 다른가

| 단계 | 실제 사례 (`cases/`) | 참조 사례 (여기) |
|---|---|---|
| 면담 | 참여자 면담 | `01-needs-from-literature.md`: 연구 대상자의 특성과 결과 |
| 측정 | 사용자 실측 | 연구가 보고한 값. 연구에 없는 치수는 **"실측 필요"**로 남김 |
| 설계·출력 조건 | 같음 | 같음. `cad/params.json`이 CI에서 렌더링됨 |
| 전달 전 점검 | 출력물로 점검 | 계산으로 가능한 항목만 채우고, 출력물이 필요한 항목은 비워 둠 |
| 실사용 평가 | `evaluation.csv` | **없음.** 지어낸 평가 데이터를 넣지 않습니다. 대신 `expected-outcomes.md`에 연구가 보고한 결과와 그 한계를 적음 |

평가 도구(`tools/at_eval.py`)는 `cases/`만 읽으므로, 참조 사례는 사업계획서의 정량 목표에 포함되지 않습니다.

## 렌더링

```sh
openscad -p reference/ref-01-eating/cad/params.json -P ref01-38mm \
  -o ref01-38mm.stl cad/built_up_handle.scad
```

모든 매개변수 세트는 GitHub Actions에서 렌더링되고 STL이 아티팩트로 올라갑니다.
