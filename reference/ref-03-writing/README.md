# ref-03: 펜을 쥐고 쓰기 (참조 사례)

> 실제 참여자가 아니라 기존 공개 설계와 연구 결과로 구성한 사례입니다. [참조 사례 안내](../README.md)

| | |
|---|---|
| 목표 동작 | 손가락 끝으로 가는 펜을 집기 어려워 서명·메모를 남에게 맡김 |
| 근거 | 기존 공개 설계 Pen Ball, Palm Pen Holder [R15]; 손잡이 지름 연구 [R1–R3] (식기·공구 연구의 **외삽**) |
| 기기 | 1순위: Makers Making Change Pen Ball을 그대로 출력. 2순위: 굵은 펜 손잡이 (`cad/built_up_handle.scad`, 둥근 홈) |
| 매개변수 세트 | `ref03-30mm`, `ref03-38mm` |

이 사례는 사업계획서의 원칙 **"처음부터 만들기보다 기존 자원을 검토하고 개선"**을 보여 주는 예입니다. 쓸 만한 공개 설계가 있으므로 새로 만들지 않는 것이 1순위입니다.
