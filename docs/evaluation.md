# 실사용 평가 기준

효과는 만족도가 아니라 **처음 정의한 목표 동작**을 기준으로 판단합니다. 모든 사례가 같은 항목, 같은 척도로 기록해야 `tools/at_eval.py`가 사업계획서의 정량 목표를 자동으로 확인할 수 있습니다.

## 기록 시점

| timepoint | 언제 | 무엇을 |
|---|---|---|
| `baseline` | 제작 전, 첫 면담·측정 시 | 기기 없이(또는 현재 쓰는 방법으로) 목표 동작 수행 |
| `v1` | 1차 시제품 **최소 14일** 실사용 후 | 1차 시제품으로 목표 동작 수행 |
| `v2`, `v3`… | 개선품 전달 후 일정 기간 사용 후 | 개선품으로 목표 동작 수행 |

## 항목 (`evaluation.csv` 열)

| 열 | 사업계획서 항목 | 값 |
|---|---|---|
| `date` | — | `YYYY-MM-DD` |
| `days_used` | 실사용 기간 | 해당 버전을 실제로 사용한 일수. baseline은 비움 |
| `task_done` | ① 목표 동작 수행 여부 | `Y` / `N` |
| `help_level` | ② 타인의 도움 필요 정도 | 아래 0–4 척도 |
| `ease` | ③ 착용·조작 편의성 | 1(매우 어려움) – 5(매우 쉬움). baseline은 비움 |
| `pain_pressure` | ④ 통증·압박 등 불편 | `Y` / `N`, 내용은 `note`에. baseline은 비움 |
| `continue_intent` | ⑤ 지속 사용 의향 | 1(전혀 없음) – 5(매우 있음). baseline은 비움 |
| `note` | — | 자유 기술. **개인 식별 정보 금지** |

### 도움 필요 정도 (`help_level`)

| 값 | 의미 |
|---|---|
| 0 | 혼자 수행 |
| 1 | 준비·감독만 필요 (예: 기기를 손에 끼워 줌) |
| 2 | 동작 일부에 약간의 도움 |
| 3 | 동작 대부분에 도움 |
| 4 | 수행 불가 / 전적으로 타인이 수행 |

같은 평가자가 같은 방법으로 관찰해 기록하는 것을 원칙으로 합니다. 사용자의 자기 보고와 관찰이 다르면 둘 다 `note`에 적습니다.

## 주요 성과지표 (KPI)

사용자별로 **최종 버전**(가장 큰 `vN`)을 `baseline`과 비교해, 다음 중 하나라도 해당하면 "개선"으로 봅니다.

- `baseline`에서 `task_done=N`이었는데 최종 버전에서 `Y` (목표 동작을 새롭게 수행), 또는
- 최종 버전의 `help_level`이 `baseline`보다 낮음 (필요한 도움 감소)

개선된 사용자가 전체의 2/3 이상(3명 중 2명 이상)이면 KPI 달성입니다.

## 확인 명령

```sh
python3 tools/at_eval.py
```

| 목표 (사업계획서) | 판정 방법 |
|---|---|
| 참여 사용자 3명 이상 | `baseline` 행이 있는 사례 수 |
| 기기별 실사용 2주 이상 | 각 사례 `v1`의 `days_used >= 14` |
| 기기별 개선 1회 이상 | 각 사례에 `v2` 이상 존재 |
| 3명 중 2명 이상 개선 | 위 KPI |
| 공개 설계 자료 3건 이상 | `stl/`에 `.stl`이 있는 사례 수 |

`PENDING`은 아직 데이터가 없다는 뜻이고, `FAIL`은 기록된 데이터가 목표에 못 미친다는 뜻입니다. 협력기관 1곳 이상, 제작 가이드 1종은 데이터로 판정하지 않으므로 이 도구가 확인하지 않습니다.

## 표준 척도와의 관계

위 5개 항목은 사업계획서가 정한 공통 항목입니다. 협력기관 작업치료사와 함께할 수 있다면 다음 표준 도구를 추가로 쓰는 것을 권합니다(자세한 근거는 [선행 사례 조사](prior-art.md)).

- **COPM** (Canadian Occupational Performance Measure): 사용자가 고른 활동의 수행도·만족도 1–10. 보조기기 서비스의 사전·사후 평가에 쓰입니다.
- **QUEST 2.0**: 보조기기와 서비스 만족도. 치수·무게·조절 용이성 등을 묻습니다.

이 도구들은 저작권이 있는 평가지이므로 문항을 이 저장소에 복사하지 않습니다.
