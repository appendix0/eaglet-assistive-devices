# 전달 전 점검

버전마다 새로 점검하고, 하나라도 통과하지 못하면 고친 뒤 다시 점검합니다.

## v1 (점검일: )

- [ ] 목표 동작을 제작자가 직접 20회 이상 반복해도 변형·파손 없음
- [ ] 체결부(나사, 벨크로, 끼움)가 풀리지 않음
- [ ] 날카로운 모서리, 버, 갈라진 층이 없음
- [ ] 피부 접촉부에 압박점이 없음 (제작자 착용 확인)
- [ ] 파손 가능 부위를 확인하고, 깨져도 날카로운 파편이 생기지 않음
- [ ] 세척 방법과 사용 가능 온도를 확인함 (PLA: 뜨거운 물·식기세척기 불가)
- [ ] 사용 중지 기준(통증, 피부 발적, 파손)과 연락 방법을 안내함
